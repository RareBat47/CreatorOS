# Glossary: CreatorOS

- **Creator Brain**: The unified memory architecture combining Stable, Episodic, and Performance memory for an individual creator.
- **Model Council**: The multi-agent LLM pipeline coordinating the Brainstormer, Scriptwriter, Critic, and Validator.
- **SceneSpec**: The canonical Zod-validated JSON specification governing a Remotion video composition.
- **Stable Memory**: Durable creator parameters that rarely change (voice, tone, banned words, brand colors).
- **Episodic Memory**: Semantic record of previously generated scripts, tested angles, and narrative arcs.
- **Performance Memory**: Empirical analytics (retention scores, watch curves, view counts) linked to formats.
- **Kinetic Captions**: Dynamic on-screen subtitle typography animated word-by-word with color highlights.
- **Talking-Head**: Video composition focused on creator A-roll with dynamic camera motion and overlays.
- **Three-Tips**: Fast-paced educational listicle video composition with card transitions.
- **Story-Arc**: Narrative-driven video composition emphasizing emotional struggle, breakthrough, and lessons.
