# 03 - Timeline Editor Specification

## 1. Studio Timeline Features
- **Player Preview**: Embedded `@remotion/player` rendering canvas in real-time.
- **Beat Track**: Visual scrub bar displaying the 5 script beats (Hook, Setup, Insight, Reframe, CTA).
- **Caption Editor**: Click-to-edit inline caption tokens and adjust frame timings.
- **B-Roll Layer Track**: Drag-and-drop overlay clips and graphics.
