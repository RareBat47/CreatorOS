# 02 - Screens & Routes: CreatorOS

## 1. Application Routes (Next.js 15 App Router)
- `/`: Marketing landing page & pricing.
- `/login`, `/register`: Better-Auth authentication.
- `/dashboard`: Project overview, recent renders, and publishing stats.
- `/studio`: Main creation workspace (Topic input -> Model Council -> Preview).
- `/brain`: Creator Brain settings (Voice, tone, banned words, visual assets).
- `/settings`: Account, team seats, and subscription billing.
