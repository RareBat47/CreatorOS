# 04 - Revision & Memory Rules Specification

## 1. Revision Rules
1. **Rule 1 (Zero Banned Words)**: Any generation containing a banned word from the creator's profile must be automatically rejected and regenerated.
2. **Rule 2 (WPM Pacing Limits)**: Spoken words per minute must stay strictly between 135 and 165 WPM. If pacing exceeds 165 WPM, sentences must be pruned.
3. **Rule 3 (Hook Window)**: The hook beat must never exceed 90 frames (3 seconds at 30fps).
4. **Rule 4 (Clear CTA)**: The closing CTA must occupy the final 5-10 seconds and have an explicit single action.

## 2. Memory Update Triggers
- When a video receives > 10,000 views or > 70% average watch time, its hook and layout pattern are committed to Performance Memory.
