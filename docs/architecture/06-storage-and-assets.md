# 06 - Storage & Assets: CreatorOS

## 1. Storage Abstraction
CreatorOS uses an S3-compatible interface for asset storage.
- **Local Development**: MinIO container (`http://localhost:9000`) with bucket `creatoros-assets`.
- **Production**: Cloudflare R2 or AWS S3 with CDN delivery.

## 2. Bucket Organization
```
creatoros-assets/
├── creators/
│   └── {creatorId}/
│       ├── avatars/
│       ├── logos/
│       └── custom-fonts/
├── uploads/
│   └── {creatorId}/
│       └── raw-a-roll/        # User-uploaded talking head clips
├── b-roll/
│   └── curated-library/       # System b-roll stock clips
└── renders/
    └── {creatorId}/
        └── {sceneId}.mp4      # Final rendered output MP4
```

## 3. Presigned URLs
All client video downloads and uploads use short-lived presigned URLs (15-minute expiration) generated by the API server. No raw S3 credentials are exposed to frontend clients.
